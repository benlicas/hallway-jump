Bonus reward videos.

Name each file after the character id:
  ashley.mp4   jeff.mp4   bj.mp4   jr.mp4

A character unlocks their video by scoring 500 points in one run
(REWARDS.score in src\config.js). Until a file is added here, the
player shows "Bonus video coming soon!".

Keep videos small: 720p MP4, ideally under ~10 MB each.
